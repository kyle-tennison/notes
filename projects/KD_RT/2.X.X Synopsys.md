**Model Changes**   

Autoencoder model
- Intruded this new model
- Mean absolute error for training
- Creates 128 dim non-normalized latent
- 4 convolution up/down steps


Normalizing model

- Uses autoencoder latent now
	- Input data was log shifted using a *z-score standardization on the log of the data*
   $$\frac{\ln (\bar x)-\mu}{\sigma}$$

- Best normalizing model is at 11.06% relative MSE on version `2.6.0`
